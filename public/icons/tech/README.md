# Tech Stack icons

The SVGs come from [theSVG](https://thesvg.org/), listed in display order:

- [Java](https://thesvg.org/icon/java)
- [Python](https://thesvg.org/icon/python?variant=mono)
- [Go](https://thesvg.org/icon/go?variant=mono)
- [C](https://thesvg.org/icon/c?variant=mono)
- [Spring Boot](https://thesvg.org/icon/spring-boot?variant=mono)
- [FastAPI](https://thesvg.org/icon/fastapi?variant=mono)
- MySQL: dolphin-only [light](https://thesvg.org/icon/mysql?variant=light) and [dark](https://thesvg.org/icon/mysql?variant=dark) variants.
- [React](https://thesvg.org/icon/react?variant=mono)
- [Next.js](https://thesvg.org/icon/nextdotjs?variant=mono)
- [Git](https://thesvg.org/icon/git?variant=mono)
- [Linux](https://thesvg.org/icon/linux?variant=mono)
- [Docker](https://thesvg.org/icon/docker?variant=mono)
- [Kubernetes](https://thesvg.org/icon/kubernetes?variant=mono)

Source assets: `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/{slug}/mono.svg`. Java uses `java/default.svg` and is rendered monochrome with CSS. MySQL uses `mysql/light.svg` and `mysql/dark.svg`, displayed at 18px; the light asset is filtered to black, and the dark asset is already white. The site's theme selects the appropriate asset.

Icons are served locally for GitHub Pages and displayed in black in light mode and white in dark mode. The compact badges use the same icon-and-label layout as the Skills section on [Aryan Karma’s site](https://aryankarma.com/).
